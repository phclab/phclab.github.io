Hardware + code

Open-Source Magnetic System for Wireless Neuromodulation

CAD models and Python control scripts for a magnetic system that drives neuromodulation in vitro and untethered brain stimulation in vivo. Includes a step-by-step build guide.

Huang, Yen, Cheng, Fang & Chiang. Scientific Reports 15, 17814 (2025).

Project page → Web tool

CoilDesignTool

Solenoid design and optimisation in the browser: current, voltage and power for a target field, 2D field maps, parameter sweeps, and a FEMM 4.2 script to verify the design. Available in 16 languages.

PHCSSM

Reference implementation of the Parallelized Hierarchical Connectome, a spiking state-space model with biological constraints inside a fully parallel recurrence. Use it to analyse time-series data such as EEG, to build language models, or to train circuits reconstructed from real brain connectomes.

Chiang. Array, 101315 (2026).
