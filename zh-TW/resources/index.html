開源無線神經調控磁刺激系統

可用於體外神經調控與活體無線腦刺激的磁刺激系統，提供 CAD 模型、Python 控制程式與逐步組裝指南。

Huang, Yen, Cheng, Fang & Chiang. Scientific Reports 15, 17814 (2025).

專案網頁 → 網頁工具

CoilDesignTool

在瀏覽器裡設計與最佳化螺線管：依目標磁場計算電流、電壓與功率，產生 2D 磁場分布、參數掃描，並匯出 FEMM 4.2 腳本驗證。支援 16 種語言。

PHCSSM

平行化階層連接體（Parallelized Hierarchical Connectome）的參考實作：在完全平行化的遞迴中保留生物限制的脈衝狀態空間模型。可用來分析時間序列資料（例如 EEG）、建構語言模型，或訓練依真實連接體重建的腦神經迴路。

Chiang. Array, 101315 (2026).

授權：PolyForm Noncommercial 1.0.0，僅限非商業用途。專利申請中，商業授權請洽陽明交大產學創新處。

GitHub → 線上遊戲
